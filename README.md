# [Add - VOICEROID BNver]

Mod ID: VOICEROID_mod

- Authors: shaba
- DDA maintainers: YasuYasu
- BN port: sagittarius72

## Overview

This mod lets you change the look of the characters made by shaba into the image characters of VOICEROID, Otomachi Una Talk Ex, CeVIO, Gynoid Talk, Galaco Talk and Kasane Teto.
It is maintained and extended by YasuYasu and volunteers on Discord.
The original mod was made for DDA ver I; this is a port to BN 0.12.0.

This mod was ported to BN with the assistance of Claude Opus.

## What this mod adds

Items and skins for the characters of VOICEROID, Otomachi Una Talk Ex, CeVIO, Gynoid Talk, Galaco Talk, VOICEVOX and Kasane Teto.
Some gimmicks were removed in the move to BN (such as the Zunda Arrow). Thank you for understanding.

Game text is in Japanese. With the game language set to English, the mod's text is shown in English (lang/en.mo).

## Installation

Unzip the downloaded zip file and put it in your mods folder.
